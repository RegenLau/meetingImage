# 启动说明

这个项目不需要 Python、Node.js 或数据库。发给同事时，把整个 `meetingImage` 文件夹打包发过去即可。

## Windows 启动方式

1. 解压 `meetingImage` 文件夹。
2. 双击 `start.bat`。
3. 浏览器会自动打开本地页面，地址类似 `http://127.0.0.1:8765/`。
4. 使用期间不要关闭弹出的命令行窗口。
5. 用完后关闭命令行窗口，或在窗口里按 `Ctrl+C` 停止服务。

如果浏览器没有自动打开，可以手动复制命令行窗口里显示的地址到浏览器。

## 注意事项

- 需要保留 `assets` 文件夹，里面是页面用到的图片和图标。
- 如果 8765 端口被占用，脚本会自动尝试后面的端口。
- `start.bat` 使用 Windows 自带 PowerShell 启动本地静态服务，不需要额外安装运行环境。
